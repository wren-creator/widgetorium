WIDGETORIUM-LAB-FLAG: db-file-read-via-LOAD_FILE

If you are reading this through the widget store's price/quantity API, you have
confirmed that the injectable endpoint reaches LOAD_FILE() and that the database
user holds the FILE privilege with secure_file_priv unset.

Note: LOAD_FILE() reads the *database container's* filesystem, not the web
server's. This file lives at /var/lib/mysql-files/secret.txt inside the db
container. Other worthwhile targets from here: /etc/passwd, /etc/hostname,
/etc/mysql/conf.d/widgetorium.cnf.
